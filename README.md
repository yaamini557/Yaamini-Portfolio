# Yaamini V M — Portfolio Website

A responsive, monochrome personal portfolio built with HTML, CSS and JavaScript.

## Run locally
1. Extract the ZIP file.
2. Open the `yaamini-portfolio` folder in VS Code.
3. Open `index.html` in a browser, or use the VS Code Live Server extension.
4. To update your portrait, replace `assets/profile-portrait.png` with your preferred image, keeping the same filename.

## Customize before publishing
- Review all project descriptions and statuses.
- Add a PDF resume and a working download link if you want a CV button.
- Add GitHub and project demo links when available.
- Verify certificate names and dates against the original certificates.
- Update contact details if needed.

## Publish with GitHub Pages
1. Create a GitHub repository, for example `yaamini-portfolio`.
2. Upload the contents of this folder (not the ZIP itself).
3. In the repository, open **Settings → Pages**.
4. Under Build and deployment, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)` folder, then Save.
6. GitHub will provide your published website URL after deployment.

The website uses Google Fonts when an internet connection is available; fallback fonts are included.
